Sobre o GameVerse

O GameVerse é um portal fictício criado para reunir jogos indie de diferentes gêneros em uma vitrine única — do RPG ao puzzle casual — com foco em curadoria e descoberta.

Sobre o Desenvolvedor

O GameVerse foi desenvolvido por João Pedro, estudante de Sistemas de Informação no IFCE Campus Aracati, como trabalho avaliativo da disciplina de Desenvolvimento Web. O projeto foi construído com HTML e CSS puro — sem frameworks — como forma de aprofundar o domínio de Flexbox, CSS Grid e recursos avançados de CSS3.

Entre os desafios do projeto, destaca-se a criação de um modal de imagem funcional sem uma linha de JavaScript, usando apenas o comportamento nativo do seletor :checked em conjunto com o combinador de irmão geral (~). Essa e outras soluções estão detalhadas no README do repositório.

Nossos Valores

Curadoria

Cada jogo listado passa por uma seleção cuidadosa, priorizando qualidade sobre quantidade.

Acessibilidade

Interface pensada para navegação por teclado e leitores de tela, sem abrir mão do visual.

Comunidade

Espaço para descobrir estúdios independentes que raramente aparecem nas grandes lojas.
